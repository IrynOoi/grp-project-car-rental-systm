## ​STELLAR CAR RENTAL SYSTEM(Mini Project for Data Structure and Algorithm)




## 📌 Overview
The **Stellar Car Rental System** is a C++ console-based application designed to manage vehicle rentals efficiently. It supports motorcycles and economy cars with different rental durations, allowing users to browse, search, and rent vehicles while generating invoices.

This project demonstrates the practical application of **Data Structures and Algorithms (DSA)** concepts in a real-world scenario.

---

## 🎯 Objectives
- Build a rental system with login functionality
- Allow users to browse and search vehicles
- Implement rental fee calculation
- Generate invoices automatically
- Apply DSA concepts learned in class

---

## ⚙️ Features
- 🔐 User login system
- 🚘 Browse available vehicles (Motorcycles, Economy Cars)
- 🔎 Search by:
  - Car category
  - Car model
- 💰 Rental fee calculation based on duration
- 🧾 Invoice generation (`Invoice.txt`)
- ✅ Input validation for:
  - Customer names
  - Rental duration

---

## 🧠 Data Structures & Algorithms Used
- **Linked List**
  - Used to store vehicle categories (M, E1, E2)
- **Insertion Sort**
  - Keeps car codes sorted
- **Sentinel Search**
  - Efficient category lookup
- **Binary Search**
  - Fast model searching

---

## 🏗️ System Design
The system is built using Object-Oriented Programming (OOP) concepts with the following classes:

- `Car` → Stores vehicle details  
- `CManager` → Manages car data  
- `Rent` → Handles rental operations  
- `Welcome` → Manages user interface and login
